# Pulsar Candidate Classification in R

A comparative machine-learning study of pulsar candidates using a 12,528-row dataset derived from HTRU2. This repository contains the R analysis associated with the IEEE conference paper [“A Machine Learning Approach for the Identification and Estimation of Pulsars upon Statistical Analysis”](https://ieeexplore.ieee.org/document/10276169).

## Research question

Radio surveys produce many candidate signals, but only a small share are pulsars. This project compared three supervised-learning approaches for distinguishing pulsar candidates from non-pulsars using eight statistical features derived from integrated pulse profiles and DM-SNR curves.

The bundled dataset contains 11,375 non-pulsar rows and 1,153 pulsar rows, so overall accuracy alone can hide poor minority-class performance. The analysis therefore also reports Cohen's kappa and balanced accuracy.

## What I implemented

- Data inspection and missing-value analysis in R
- Predictive mean matching with MICE for incomplete feature values
- Feature scaling and exploratory correlation analysis
- MARS, k-nearest-neighbour, and neural-network classifiers
- Holdout confusion matrices and repeated cross-validation for the KNN and neural-network models

The work formed part of my data-analysis research internship at Vellore Institute of Technology.

## Data

The repository includes `pulsar_data_train.csv`, a 12,528-row candidate dataset with:

- Eight continuous input features
- One binary target, where `1` denotes a pulsar candidate
- 3,538 missing feature cells handled in the historical analysis with MICE

The positive class accounts for approximately 9.2% of the rows.

## Evaluation

The historical analysis uses a stratified 80/20 train-test split. KNN and the neural network are trained with repeated 10-fold cross-validation using three repeats.

The rendered report records the following holdout results:

| Model | Accuracy | Cohen's kappa | Balanced accuracy |
|---|---:|---:|---:|
| MARS | 0.9780 | 0.8599 | 0.9039 |
| KNN | 0.9772 | 0.8523 | 0.8937 |
| Neural network | **0.9800** | **0.8749** | **0.9187** |

For the neural network, the holdout confusion matrix is:

| Predicted | Actual non-pulsar | Actual pulsar |
|---|---:|---:|
| Non-pulsar | 2,261 | 36 |
| Pulsar | 14 | 194 |

Using the pulsar class as positive, this corresponds to approximately **0.933 precision**, **0.843 recall**, and **0.886 F1**.

> The report generated by `caret::confusionMatrix` treats class `0` as positive by default. Its displayed 0.9843 positive predictive value is therefore for non-pulsars, not pulsars.

## Important evaluation limitation

The original script performs MICE imputation and min-max scaling before the train-test split. Information from the holdout feature distribution can therefore influence preprocessing.

The table above reproduces the historical project output, but it should not be presented as a fully leakage-safe estimate of performance. A stronger rerun would split first, fit every preprocessing step on training data only, and evaluate a pipeline that preserves the class imbalance.

## Run the analysis

Install the required R packages:

```r
install.packages(c(
  "caret",
  "mice",
  "skimr",
  "corrplot",
  "tidyverse",
  "ggplot2",
  "neuralnet",
  "nnet",
  "earth"
))
```

From the repository root:

```r
source("Identification of Pulsar stars.r")
```

The committed HTML file preserves the original rendered output. Exact package versions were not recorded, so numerical reproduction may vary across current R environments.
